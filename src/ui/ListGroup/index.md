# ListGroup 列表

列表组件系列提供了多种数据展示和交互方式，适用于不同的业务场景。

## 卡片列表 - ItemListCard
用于展示带标题、操作按钮的卡片式列表，支持添加、刷新、关联等操作。

**适用场景：**
- 数据管理界面的列表展示
- 需要对列表进行操作的场景
- 带标题的内容容器

<embed src="./ItemListCard/index.md"></embed>

## 轮播列表 - ListCarousel
垂直连续滚动的轮播组件，支持数据轮播展示、自动轮播控制、间隔时间配置和多种动画效果。

**适用场景：**
- 公告、新闻、通知的滚动展示
- 有限空间内的多信息展示
- 需要吸引用户注意力的场景

<embed src="./ListCarousel/index.md"></embed>

## 搜索列表 - ListSearch
带搜索功能的选择列表组件，支持单选、多选模式，带有搜索过滤功能。

**适用场景：**
- 表单中需要从大量选项中选择
- 需要搜索过滤的选择器
- 弹窗或下拉容器中的选择控件

<embed src="./ListSearch/index.md"></embed>

## 搜索列表增强版 - ListSearch2
ListSearch 的增强版本，增加了更多样式配置和分类功能。

**适用场景：**
- 需要颜色标识的选项列表
- 带分类筛选的选择器
- 更丰富样式配置的场景
