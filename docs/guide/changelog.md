# 更新日志

这里记录了 allah-antd 的所有版本更新说明。

## 6.6.0 (2026-01-09)

### 新特性
- 🆕 `AhCardListPage` 组件新增 `addData` 方法，支持单条或批量添加数据到列表
- 🆕 `AhCardListPage` 组件新增 `deleteData` 方法，支持根据主键删除列表中的数据

### 优化
- 🔨 完善 `IAhCardListPageFunc` 类型定义，补充 `addData` 和 `deleteData` 方法声明

## 6.5.5 (2025-11-19)

### 新特性
- 🆕 新增标签选择组件
- 🆕 添加本地上传文件方法
- 🆕 添加tailwindcss兼容样式

### 优化
- 🔨 优化文件上传逻辑并移除调试代码
- 🔨 更新文档结构和样式指南
- 🔨 添加 pnpm-workspace.yaml 配置文件

### 问题修复
- 🐞 修复 IconText 组件仅在有点击事件时显示指针样式的问题

## 6.0.13 (2025-02-25)
